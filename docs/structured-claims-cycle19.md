## Implementation and scope

`newdomain/structured_claims.py` selects exact source units using mode plus claim/source/condition/attribution attachment IDs, then renders deterministic source-labelled quotations. Unknown IDs, detached attachments, duplicate keys/units, mixed clarification/factual modes, incomplete envelopes and changed catalog hashes fail validation. Clarify/abstain render fixed text. Complete sentences preserve parentheses, and exact opening policy titles attach as provenance. Overlong units are omitted rather than truncated; all original selected evidence stays visible. Speaker neighborhoods are explicitly semantically unverified.

This is a narrower first step than independently validated typed semantic claims. Condition/attribution IDs bind whole source units, not proven relationships. Exactness does not prove relevance, completeness or speaker ownership. It also changes wording, schema, validator and maximum rendered length900characters; the trial does not isolate an effect of fields alone. No production integration/default change.

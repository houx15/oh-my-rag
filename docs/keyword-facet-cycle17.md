# Cycle17: a selection repair recovers content but exposes generation risks

The frozen facet selector recovers N417's historical valuation in all three query arms and restores GM068's missing flexible-computing evidence in the Qwen arm. It does not establish a broad improvement: two other arms omit a crucial performance condition, attribution remains incomplete in two valuation answers, and existing policy-scope errors persist. C1 remains default; the selector is an opt-in development module.

Other53/60 Cycle16 preparations are unchanged offline, not freshly reanswered regressions. Freeze includes a pre-answer source audit of all seven substitutions; no required useful evidence loss found.

Implementation recognizes named-author valuation and broad research-achievement questions, preserves already-selected evidence facets, and admits additional facets only from existing candidate views. New laboratory candidates must name the requested laboratory in the actual window. Generic synthetic unit fixtures verify invariants; they are not answer-quality holdouts.

## Exact outcomes and causal limits

- **N417: “的传承。陶弘景有没有评价过这个牛黄的价值，说它很贵呢？”** All controls answer that the selected material lacks the valuation. The facet lexical answer quotes《本草经集注》“药中之贵，莫复过此” and “好者直五六千至一万也”, preserving book-level attribution. The dictionary answer gives the same substance but opens with a conflicting broad absence claim. Qwen's added MD-038-0008 actually contains弘景曰 before the quotation: its answer “陶弘景称牛黄‘药中之贵，莫复过此’” is source-supported, but its delivered short quote omits the speaker and the《本草纲目》transmission chain. This is real content recovery; explicit-speaker evidence is a Qwen candidate contribution, while book-level valuation was already recoverable without Qwen.
- **GM068, 光明实验室代表性科研成果.** Qwen control covers carbon evaluation and awards but loses flexible computing. Facet Qwen adds the flexible-computing result and explicitly retains “相比业界主流弹性计算架构，在承载等量业务规模前提下可节省40%+算力资源”. Conditional grade partial→complete. Lexical and dictionary controls already cover flexible computing in other slides; adding the detailed result induces “可节省40%+算力资源” without the equal-workload condition. Their complete→partial changes are generation condition omissions, not retrieval failures, and must not be hidden by the unchanged binary passes. Existing sources were preserved; more evidence did not guarantee safer claims.
- **GM064: “介绍一下光明区的科研成果。”** Facet Qwen uses the newly selected D30:1 overview:10 institutes,381 collected results,171information/166life/44materials. This is optional inventory enrichment; the control already gives carbon and flexible-computing achievements, so both are complete. Lexical and dictionary contexts/messages are identical between selectors: lexical control is malformed while its fresh counterpart is valid but overgeneralizes subsidy eligibility; dictionary repeats the policy-scope error. These differences cannot be attributed to changed selection. Policy facts were not independently redesigned in this experiment.

The actionable research decomposition is candidate recall → evidence selection/coverage → attributed and condition-preserving generation. These are known RAG problems, not a novelty claim. Selection is now shown to be repairable on a specific valuation case; broader entity vocabulary and ranking remain separate hypotheses. The observed condition-loss tradeoff and source-conditional metric limit prevent default promotion. Next confirmation should freeze an end-to-end factual-facet rubric that distinguishes a safe selected-source abstention from task completion when a corpus witness exists, include unaffected controls and genuine unseen original questions, and measure actual live selective fallback before an efficiency claim. Existing exposed originals and synthetic checks cannot substitute for that holdout.

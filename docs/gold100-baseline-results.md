# 固定100题：Simple-RAG-v1 baseline（2026-10-15）

已完成100/100次新生成、100/100逐题助手评审，无重试、无删题。此轮建立新的固定对照，不与旧6/60/68题分数混比，也不宣称已经超过旧系统。

## 题库与抽样

原始业务815行：光明420、牛黄395。光明排除90、牛黄排除64，再合并牛黄16个重复别名，得到645道可用业务题；加20道独立回归题，共665个不同题号及不同问题文本。仍有语义近似题，不声称665个独立意图。

本集合固定光明50、牛黄40、回归10。按已知失败风险定向覆盖条件/上限、跨页流程、数量与单位、对象比较、语音别名/歧义、资料缺失、时效/研发阶段、古籍与现代证据边界，也含普通介绍。它是暴露过的开发挑战集，不代表真实流量分布或未见测试集。

金标以筛选后的原文、原始目录字段、可复算条目统计为依据，由助手核对。含必答要点、允许边界、禁忌推断与来源。歧义/拒绝伪造/急救引导等属于行为评分规则，不能假装都是语料事实。未做独立人工专家审阅或全量影像/OCR核对。标注文件与模型输入在生成前冻结，原参考答案不进入推理检索。

## Baseline

500字符固定切块、80字符重叠；中文二元词与英文/数字分词；BM25(k1=1.2,b=.75, IDF=log(1+(N-df+.5)/(df+.5)))取前5块、同分按ID。一次deepseek-v4.1-flash调用，thinking=false、temperature=.2、max_tokens=800。无查询改写、重排、图谱、预计算计数、旧优化管线或失败修复。

牛黄保留原文和书名、作者、卷次、版本、馆藏等原始目录字段，剔除历史生成的统计、别名和改写。10道回归题从各自历史fixture源池检索，单列，不冒充完整业务检索。三类数据总览不能掩盖这个差异。

## 失败与正例

25个机械失败中：20个仅空白/换行不一致，3个非空白引文失配，2个输出截断。只作诊断，不事后放宽validator或把失败改成通过。语义全对但机械失败的15题，与真正内容错误分开看。

检索遗漏：西田/玉律承重漏下一页、投资退出的收入或利润条件漏后页、目录计数题只取局部片段。生成误判：把损坏单位确定补成平方厘米、把GDP OCR片段误作亿元、把连续但未完整的引文判成非连续。输出冗余：长引文重复导致两题达到800token限制后截断，急症/个人用药问题附过多无关古方。

正例同样保留：GM349的跨页流程这次找到并完整回答；GM120提供了可支持的介绍；基金认缴/实缴、馆藏版本和多项时效边界题正确。因此不应按题号写补丁，也不应把某次单题成败认定为稳定能力。

评分复核保留了初评和一项修订：GM197答案已明确申请年度及审核限制，符合冻结的“不承诺当前获批”要点，撤销了额外要求主动给出到期日期的扣分；原始53/38与最终54/39的差异可查review-amendments.json。未修改金标、题目或输出。

## 后续可比实验规则

每轮先登记策略、假设、唯一主要改动、代码/config哈希与资源预算；同100题、同语料、同模型参数、同评分规则新生成100次。报告逐题净增益/回退、各风险层结果、平均/p95延迟、4.7秒达标、总/均价和离线构建成本。更换模型、语料、标签或评分规则必须新版本并同步重算/重跑必要对照，不能只换候选侧。

当前只有baseline已执行。候选计划：E01降低引文生成负担（源片段定位后确定性渲染，保持最终引文验证规则）；E02检索片段补齐文档标题与相邻条款依赖；E03离线建立有版本及来源的目录聚合事实。三项各自独立与baseline比较，先不混搭，不预填提升结果。先处理E01，可检验格式/长度问题是否能在不损害语义的前提下降低延迟。
